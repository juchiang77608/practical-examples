# practical-examples

Small, self-contained demos for architecture ideas.

| Folder | What it demonstrates |
|---|---|
| [`embedded-common-shell`](./embedded-common-shell) | Host embeds an independent Common SPA in a fullscreen iframe; communication via `postMessage`. |
| [`micro-frontend-common`](./micro-frontend-common) | Host loads Common as a Module Federation remote and mounts it into the same DOM; communication via callbacks. |
